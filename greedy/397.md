# LeetCode 397. Integer Replacement

**Difficulty:** Medium  
**Topics:** Greedy, Bit Manipulation, Math

## 1. Problem Statement

Given a positive integer `n`, we need to make it equal to `1` using the minimum number of operations.

Allowed operations:

1. If `n` is even, divide it by 2.
2. If `n` is odd, either add 1 or subtract 1.

Return the minimum number of operations required.

### Example 1

```cpp
Input: n = 8

8 -> 4 -> 2 -> 1

Output: 3
```

### Example 2

```cpp
Input: n = 7

7 -> 8 -> 4 -> 2 -> 1

Output: 4
```

---

## 2. Approach: Greedy + Bit Manipulation

### Key Observation

Our goal is to reach 1 in minimum operations.

- If the number is even, we have no choice. Divide it by 2.
- If the number is odd, we have two choices: `n + 1` or `n - 1`.

For odd numbers, we should choose the operation that creates more trailing zeros in binary representation.

**Why?**

Because more trailing zeros mean we can divide by 2 more times.

### Example 1: n = 7

```text
7 = 111

Option 1: Add 1

7 -> 8 -> 4 -> 2 -> 1

8 = 1000
```

Adding 1 creates three trailing zeros.

```text
Option 2: Subtract 1

7 -> 6 -> 3 -> 2 -> 1

6 = 110
```

Adding 1 is better because it allows more consecutive divisions by 2.

### Example 2: n = 13

```text
13 = 1101

Subtract 1:

13 -> 12

12 = 1100
```

Subtracting 1 creates two trailing zeros.

Therefore, subtract 1.

---

## 3. How to decide using Bit Manipulation?

We only need to check the last two bits of an odd number.

We use:

```cpp
num & 3
```

Why 3?

```text
3 = 11 (binary)
```

Bitwise AND checks the last two bits and ignores all the other bits.

### Case 1: Last two bits are 01

```text
num = 13 = 1101
             &
             0011
             ----
             0001 = 1
```

So:

```cpp
(num & 3) == 1
```

We subtract 1.

### Case 2: Last two bits are 11

```text
num = 7 = 111
            &
            011
            ---
            011 = 3
```

So:

```cpp
(num & 3) == 3
```

We add 1.

### Case 3: Even number

We check the last bit using:

```cpp
(num & 1) == 0
```

If the last bit is 0, the number is even.

We divide it by 2 using right shift:

```cpp
num = num >> 1;
```

Right shift by one is equivalent to dividing a non-negative integer by 2.

---

## 4. Special Case: n == 3

There is one important exception.

For `n = 3`:

```text
3 = 11
```

Our general rule suggests adding 1 because the last two bits are `11`.

But compare:

```text
Add 1:

3 -> 4 -> 2 -> 1

Total = 3 operations
```

```text
Subtract 1:

3 -> 2 -> 1

Total = 2 operations
```

Therefore, we handle `num == 3` separately.

---

## 5. C++ Solution

```cpp
class Solution {
public:
    int integerReplacement(int n) {
        long long num = n;
        int ans = 0;

        while (num != 1) {

            // If even, divide by 2
            if ((num & 1) == 0) {
                num = num >> 1;
            }

            // If last two bits are 01, subtract 1
            // Special case: num == 3
            else if (num == 3 || (num & 3) == 1) {
                num = num - 1;
            }

            // If last two bits are 11, add 1
            else {
                num = num + 1;
            }

            // Count every operation
            ans++;
        }

        return ans;
    }
};
```

| 7 | 111 | Last two bits = 11 | +1 |

## 7. Important Takeaways

1. Greedy means choosing the operation that helps us reach the goal faster.
2. For even numbers, always divide by 2.
3. For odd numbers, check the last two bits.
4. `num & 1` checks the last bit.
5. `num & 3` checks the last two bits.
6. If `num & 3 == 1`, subtract 1.
7. If `num & 3 == 3`, add 1.
8. Special case: `num == 3`, subtract 1.
9. Use `long long` because `INT_MAX + 1` can overflow an `int`.
10. `num >> 1` is equivalent to dividing a non-negative integer by 2.

### Complexity Analysis

- **Time Complexity:** O(log n), because the number reduces approximately by half after every one or two operations.
- **Space Complexity:** O(1), because we use only a few variables.
