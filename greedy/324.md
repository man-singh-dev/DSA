# LeetCode 324 — Wiggle Sort II

## 1. Problem Statement

Given an integer array `nums`, rearrange it such that:

```text
nums[0] < nums[1] > nums[2] < nums[3] > nums[4] ...
```

We need to arrange the elements in this wiggle pattern.

Example:

```text
Input:  [1, 5, 1, 1, 6, 4]
Output: [1, 6, 1, 5, 1, 4]
```

---

## 2. Key Observation (Hinglish)

Sabse important observation:

- **Even indices (0, 2, 4...)** par smaller elements chahiye.
- **Odd indices (1, 3, 5...)** par bigger elements chahiye.

Why?

Because the required pattern is:

```text
small < BIG > small < BIG > small
```

Therefore:

- Even index → Take elements from the LEFT half of sorted array.
- Odd index → Take elements from the RIGHT half of sorted array.

**Important trick:** Dono halves ko right se left traverse karna hai.

---

## 3. Approach — Sorting + Two Pointers

First, make a copy of the original array and sort it.

```cpp
vector<int> arr = nums;
sort(arr.begin(), arr.end());
```

Now initialize two pointers:

```cpp
int left = (n + 1) / 2 - 1;
int right = n - 1;
```

### Why these starting positions?

Suppose:

```text
arr = [1, 2, 3, 4, 5, 6]
```

Here `n = 6`.

```cpp
left = (6 + 1) / 2 - 1 = 2;
right = 6 - 1 = 5;
```

So:

```text
Index:       0  1  2  3  4  5
Sorted:      1  2  3  4  5  6
                  ↑        ↑
                 left    right
```

- `left = 2`: Last element of the smaller half.
- `right = 5`: Last element of the bigger half.

Now traverse the original array:

**Case 1: Even index**

```cpp
nums[i] = arr[left--];
```

Take a smaller element and move left pointer backwards.

**Case 2: Odd index**

```cpp
nums[i] = arr[right--];
```

Take a bigger element and move right pointer backwards.

### Why are we using `left--` and `right--`?

Consider:

```cpp
nums[i] = arr[right--];
```

This is equivalent to:

```cpp
nums[i] = arr[right];
right = right - 1;
```

First, current element gets assigned. Then pointer decreases.

Same logic applies to `left--`.

---

## 4. Complete C++ Code

```cpp
class Solution {
public:
    void wiggleSort(vector<int>& nums) {

        vector<int> arr = nums;

        sort(arr.begin(), arr.end());

        int n = nums.size();

        int left = (n + 1) / 2 - 1;
        int right = n - 1;

        for (int i = 0; i < n; i++) {

            if (i % 2 == 0) {

                // Even index: smaller element
                nums[i] = arr[left--];

            } else {

                // Odd index: bigger element
                nums[i] = arr[right--];

            }
        }
    }
};
```

Input:

```text

```

Check:

```text
1 < 6 > 1 < 5 > 1 < 4
```

Required pattern achieved!

## 7. Common Mistakes

1. Don't take bigger elements at every index.
2. Even indices need smaller elements.
3. Odd indices need bigger elements.
4. `left` should start at `(n + 1) / 2 - 1`, not at 0.
5. `right` should start at `n - 1`.
6. Both pointers move backwards because we consume each half from right to left.

### One-line revision trick

**Even = Smaller = Left half**

**Odd = Bigger = Right half**

**Both pointers move backwards.**

## 9. Important Difference: Wiggle Sort I vs Wiggle Sort II

### Wiggle Sort I — LeetCode 280

Pattern:

```text
nums[0] <= nums[1] >= nums[2] <= nums[3]
```

Equal adjacent elements are allowed.

### Wiggle Sort II — LeetCode 324

Pattern:

```text
nums[0] < nums[1] > nums[2] < nums[3]
```

Strict inequalities are required.

Duplicates make Wiggle Sort II more challenging.

**Practice tip:** First solve LeetCode 280, then solve LeetCode 324 again without looking at the solution.
