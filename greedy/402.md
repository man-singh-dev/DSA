# 402. Remove K Digits
**Difficulty:** Medium | **Topics:** Greedy, Monotonic Stack, String
## 1. What is the question saying?
Given a string `num` representing a number and an integer `k`, remove exactly `k` digits such that the remaining number is as small as possible.
- Relative order of remaining digits must be maintained.
- Leading zeroes are not allowed.
- If no digits remain, return `"0"`.
**Example:**
```cpp
num = "1432219", k = 3
Output = "1219"
```
## 2. Main Idea / Observation
We need to make the number as small as possible.
**Key observation:** Agar previous digit current digit se bada hai, toh previous digit ko remove karna better hai.
Example:
```text
1432
```
If we remove `4`, we get `132`, which is smaller.
So, whenever:
```cpp
st.back() > digit
```
Remove the previous digit.
**Why Stack?**
Humein previous inserted digit ke saath current digit compare karna hai. Stack ka `back()` last inserted digit deta hai, so it is perfect.
We use a **Monotonic Increasing Stack** because smaller digits should come before bigger digits.
## 3. Approach
1. Create an empty string `st` and use it as a stack.
2. Traverse every digit in `num`.
3. While stack is not empty, previous digit is greater than current digit, and `k > 0`: remove the previous digit and decrease `k`.
4. Push the current digit into the stack.
5. If `k` is still greater than 0, remove remaining digits from the back.
6. Remove leading zeroes.
7. If the string becomes empty, return `"0"`, otherwise return the remaining string.
## 4. My C++ Solution
```cpp
class Solution {
public:
    string removeKdigits(string num, int k) {
        // Maintain relative order using stack
        string st = "";

        for (char digit : num) {
            // Remove bigger previous digits to make number smaller
            while (!st.empty() && st.back() > digit && k > 0) {
                st.pop_back();
                k--;
            }
            st.push_back(digit);
        }

        // If removals are still left, remove from back
        while (k > 0 && !st.empty()) {
            st.pop_back();
            k--;
        }

        // Remove leading zeroes
        int i = 0;
        while (i < st.size() && st[i] == '0') {
            i++;
        }

        st = st.substr(i);

        // If nothing remains, return 0
        if (st.empty()) {
            return "0";
        }

        return st;
    }
};
```
## 5. Dry Run
```cpp
num = "1432219", k = 3
```
| Current digit | Stack before | Action | Stack after |
|---|---|---|---|
| 1 | Empty | Push 1 | 1 |
| 4 | 1 | Push 4 | 14 |
| 3 | 14 | Remove 4, push 3 | 13 |
| 2 | 13 | Remove 3, push 2 | 12 |
| 2 | 12 | Push 2 | 122 |
| 1 | 122 | Remove 2, remove 2, push 1 | 121 |
| 9 | 121 | Push 9 | 1219 |
Exactly 3 digits removed: `4, 3, 2`.
**Final Answer = `"1219"`**
## 6. Important Code Concepts
| Code | Meaning |
|---|---|
| `st.back()` | Access last character |
| `st.pop_back()` | Remove last character |
| `st.push_back(digit)` | Add character at end |
| `st.empty()` | Check if stack/string is empty |
| `st.substr(i)` | Get substring starting from index `i` |
**Why `while` and not `if`?**
Because multiple previous digits might be greater than the current digit.
Example: Stack = `765`, current digit = `2`. We need to remove 5, 6 and 7. Hence `while`.
**Why remove from the back if k is still left?**
If digits are already in increasing order, the greedy condition won't remove anything. In that case, removing the last digits gives the smallest remaining number.
**Why leading zero removal?**
Example: `"0200"` should become `"200"`. We use `substr(i)` to remove all leading zeroes.
## 7. Key Takeaways
- When relative order must be maintained, think about Stack.
- When a bigger previous element is harmful and a smaller current element arrives, think about Monotonic Stack.
- Use `while`, not `if`, when multiple previous elements might need removal.
- Always check if `k` is still greater than zero after traversing.
- For number strings, remember leading zero handling.
- Here `string` itself works as a stack; no need for `stack<char>`.
**Time Complexity:** `O(n)` — each digit is pushed once and popped at most once.
**Space Complexity:** `O(n)` — string stack can store up to n digits.
