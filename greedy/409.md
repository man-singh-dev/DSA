# 409. Longest Palindrome
**Difficulty:** Easy  
**Topics:** Hashing, Frequency Counting, Greedy, Strings
## 1. What is the question saying?
We are given a string `s`. We need to find the length of the longest palindrome that can be formed using its characters.
- We can rearrange the characters.
- We don't need to use all characters.
- A palindrome reads the same from left to right and right to left.
**Example:**
```cpp
s = "abccccdd"
Output = 7
```
One possible palindrome is `"dccaccd"`.
We can use:
- `c` → 4 times
- `d` → 2 times
- `a` → 1 time (middle character)
Total = 7.
## 2. Main Idea / Observation
Palindrome ka structure hota hai:
```text
Left Half + Middle Character + Reverse of Left Half
```
**Important observations:**
1. Har character ko pair mein use karna padega because left aur right side same hone chahiye.
2. Agar kisi character ki frequency even hai, toh uske saare occurrences use kar sakte hain.
3. Agar frequency odd hai, toh usme se ek character extra bach jayega.
4. We can use only ONE odd-frequency character in the middle. Baaki odd frequencies se ek character discard karna padega.
**How to get the maximum even occurrences?**
```cpp
(n / 2) * 2
```
Example:
- Frequency 5 → `(5 / 2) * 2 = 4`
- Frequency 4 → `(4 / 2) * 2 = 4`
- Frequency 3 → `(3 / 2) * 2 = 2`
## 3. Approach
1. Create a frequency array to count each character.
2. Traverse the string and increase the frequency of each character.
3. Traverse the frequency array.
4. Add the maximum even occurrences using `(n / 2) * 2`.
5. If any frequency is odd, set `hasOdd = true`.
6. After the loop, if `hasOdd` is true, add exactly 1 for the middle character.
7. Return the final length.
## 4. C++ Code
```cpp
class Solution {
public:
    int longestPalindrome(string s) {
        vector<int> count(128, 0);

        // Count frequency of each character
        for (char ch : s) {
            count[ch]++;
        }

        int length = 0;
        bool hasOdd = false;

        // Calculate maximum even occurrences
        for (int n : count) {
            length += (n / 2) * 2;

            if (n % 2 != 0) {
                hasOdd = true;
            }
        }

        // Add one character in the middle
        if (hasOdd) {
            length++;
        }

        return length;
    }
};
```
## 5. Dry Run
```cpp
s = "abccccdd"
count = {a:1, b:1, c:4, d:2}
```
| Character | Frequency | Even occurrences used |
|---|---:|---:|
| a | 1 | 0 |
| b | 1 | 0 |
| c | 4 | 4 |
| d | 2 | 2 |
Total `length = 6`.
Since at least one odd frequency exists (`a` and `b`), `hasOdd = true`.
Add 1 for the middle character.
**Final Answer = 7**
## 6. Important C++ Concepts
**A. Range-based for loop**
```cpp
for (int n : count)
```
Means array ke har element ki value one by one `n` mein aayegi. Here `n` is the frequency, NOT the index.
**B. Integer division**
```cpp
5 / 2 = 2
```
C++ integer division decimal part discard kar deta hai.
**C. Modulus operator**
```cpp
n % 2 == 0  // Even
n % 2 != 0  // Odd
```
**D. Boolean variable**
```cpp
bool hasOdd = false;
```
It remembers whether we found at least one odd frequency. We add only one middle character, even if multiple frequencies are odd.
## 7. Key Takeaways
- Whenever a problem involves rearranging characters, think about frequency counting.
- Whenever we need pairs, think about even frequencies.
- Maximum even occurrences can be calculated using `(n / 2) * 2`.
- In a palindrome, at most one character can have an odd frequency because only one middle position is available.
- Use a boolean variable when you only need to remember whether something happened at least once.
- Don't add 1 for every odd frequency. Add it only once after checking all frequencies.
**Time Complexity:** `O(n)` — frequency counting takes O(n), and traversing the fixed-size array takes O(1).
**Space Complexity:** `O(1)` — fixed-size frequency array of 128 elements.
